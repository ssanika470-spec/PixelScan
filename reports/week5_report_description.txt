This report describes the Week 5 final project: the PixelScan scan dashboard, which combines everything from the previous weeks. The dashboard loads a static JSON file containing 14 file inspections using fetch, merges in any files the visitor analysed on the home page, and shows four summary figures, a bar chart of files by type, and a data table that can be searched, filtered by type and result, and sorted by any column. The layout is responsive and mobile-first, with the table scrolling inside its own container so the page never scrolls sideways. Accessibility features include a skip link, a labelled search form, aria-sort on column headers, a polite live region that announces how many rows match, status messages for loading and errors, and a text-based table that serves as the full alternative to the chart. Performance choices include deferred minified scripts, no external libraries or fonts, and a chart built with CSS bars. The report explains the design decisions, the JSON structure, the features implemented, and the testing outcomes: 21 automated browser checks passed in Chromium at 375, 768 and 1280 pixel widths, covering the menu, accordion, file validation, signature analysis, filtering and sorting. It also states what was not tested, namely Firefox, Safari and real screen readers, so that the claims in the report match the evidence. The complete source, JSON file and documentation are in the linked GitHub repository.
